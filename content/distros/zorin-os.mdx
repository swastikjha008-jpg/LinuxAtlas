## Overview

Zorin OS is an Ubuntu-based distribution designed to ease the transition from Windows or macOS, with a layout switcher that can make the desktop resemble either at install time.

## Philosophy

Zorin's stated goal is making Linux approachable enough that non-technical users switch and stay switched — polish and familiarity take priority over exposing advanced configuration.

## Installation

Zorin's installer mirrors Ubuntu's with an added "Zorin Appearance" layout picker, so new users land on a desktop that already looks like what they're used to.

## Package Management

apt underneath, with the Zorin-branded Software store as the primary GUI for most users:

```bash
sudo apt update && sudo apt upgrade
sudo apt install <package>
```

## Filesystem

ext4 by default, following its Ubuntu base.
